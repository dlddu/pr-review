mockup (화면 단위)

여정 단위로 전환되기 전의 화면 단위 산출물. 전환이 끝나면 위 여정 행의 mockup 링크가 채워진다.

화면 단위 mockup 갤러리 review-detail · gap-fill · calibration · knowledge-augment · 18단계를 4화면이 덮음 갤러리 열기 → mockup 인덱스
